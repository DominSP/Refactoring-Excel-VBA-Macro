# Excel VBA Macro Optimization — A Practical Experiment

## 📌 Project Overview

The goal of this experiment is to demonstrate how **understanding, reviewing and refactoring recorded VBA code can improve macro performance**.

Excel's Macro Recorder is a useful tool for automating repetitive tasks but the generated code often contains unnecessary instructions and operations. By reviewing and simplifying this code, it is possible to improve readability, maintainability and execution time while preserving the intended functionality.

This project compares two VBA macros that perform the same data-cleaning task:
- **Recorded Macro** — the original code generated by Excel's Macro Recorder.
- **Refactored Macro** — a manually reviewed and simplified version of the original code.

The experiment highlights the importance of not only recording automation but also understanding the code behind it.

## 🎯 Objectives

- Understand the limitations of automatically recorded VBA code.
- Practice reading and reviewing existing VBA code.
- Identify and remove unnecessary instructions.
- Refactor and simplify code without changing its intended functionality.
- Measure and compare macro execution times.
- Verify that both versions produce the same result.

## 🛠️ What Does the Macro Do?

Both macros automate a simple cleaning process in an Excel worksheet:

1. Clear the contents of selected cells.
2. Clear the contents of a table range.
3. Apply consistent cell borders to the table.
4. Measure the execution time.
5. Display the elapsed time directly in the worksheet.

The purpose is to compare the implementation of the same task, rather than to introduce different cleaning operations.

## ⚡ Performance Comparison

In my experiment, the recorded macro took approximately **0,32 seconds** to execute, while the refactored version took approximately **0,17 seconds**.

| Metric | Recorded Macro | Refactored Macro |
|---|---:|---:|
| Average execution time | 0.30 seconds | 0.15 seconds |
| Relative execution time | 100% | 50% |

**Result: approximately 50% shorter execution time.**

These results are based on my tests and may vary depending on the workbook, Excel environment and data size.

## 📂 Repository Contents

### 2. Excel Workbook

The workbook contains four worksheets for testing and comparing the macros:

The worksheets provide a practical way to compare the output and execution time of both implementations.

## 💡 Key Takeaway

This experiment demonstrates that recording a macro is only the first step in automation.
Even relatively small changes can produce meaningful performance improvements. Learning to read, review and refactor VBA code is therefore an important skill for anyone working with Excel automation.
